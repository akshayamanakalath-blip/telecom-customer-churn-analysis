**Project Title**: Telecom Customer Churn Analysis (Python EDA Project)

Project Overview:
This project analyzes customer churn behavior in a telecom company using Python.
The objective is to identify key factors influencing customer churn and provide actionable business insights.

Business Objective:
To understand:
Which customers are more likely to churn.
What factors influence churn behavior.
How retention strategies can be improved.

Tools & Libraries Used:
Python
Pandas
NumPy
Matplotlib
Seaborn

Data Cleaning Performed:
Handled missing values in target variable
Treated high null percentage columns
Converted categorical variables to numeric format
Removed unnecessary columns

Key Insights:
Customers with lower tenure are more likely to churn
Monthly charges alone are not a strong churn driver
Senior citizen status has minimal impact
Churn is influenced by multiple combined factors
Business Recommendations:
Improve early customer engagement
Strengthen onboarding process
Offer loyalty incentives for long-term retention
